# Stage 7 changelog — Space Apps Global Offer integrations (v0.7.0)

## Integrations added

### Meteomatics Weather API

- Optional authenticated backend integration using `METEOMATICS_USERNAME` and `METEOMATICS_PASSWORD`.
- Queries a six-hourly time series for temperature at 2 m, relative humidity at 2 m, wind speed and direction at 10 m, and six-hour accumulated precipitation.
- Uses the selected study-region centroid; requests are limited to 1–14 past days.
- Credentials are only read by the backend and are never sent to the browser or included in API responses.
- A 30-minute process-local cache reduces repeated provider requests.
- The feature stays disabled with an actionable configuration message until the team claims the Meteomatics Global Offer and configures credentials.

### Microsoft Planetary Computer

- Uses the public STAC API to search `modis-13Q1-061` (MODIS Vegetation Indices 16-Day, 250 m).
- Uses the Planetary Computer Data API `item/statistics` endpoint to calculate NDVI area statistics for the selected study-region bounding box.
- Returns mean, minimum, maximum, P10/P90 when available, valid-pixel percentage and count.
- Requests apply the collection scale factor (`unscale=true`) so NDVI is reported in physical index units rather than packed integer values. Statistics cap the maximum processing dimension at 512 pixels, so large-area values are sampled/downsampled summaries, not a full-resolution pixel census.
- Limited to 1–120 days and up to eight composites per request; a 30-minute cache avoids repeated work.
- Uses the public STAC/Data APIs; no Planetary Computer credentials are required for this integration.

## Scientific and security guardrails

- FIRMS remains the only source of active-fire hotspot detections.
- Meteomatics values are point samples at the region centroid; they are not conditions at every hotspot and do not prove fire causation or predict fire danger.
- MODIS NDVI is a 16-day vegetation-greenness composite, not fuel moisture, biomass, burned area, or a fire-risk score. Region statistics use the configured bounding box, not a high-resolution administrative boundary.
- Weather and NDVI are contextual layers only; they are not fed into the MODIS–VIIRS calibration model.
- Provider credentials remain server-side. Planetary Computer metadata is queried over fixed official endpoints; user input cannot supply arbitrary remote URLs.
- Missing weather or vegetation values are not filled with zeros.
