# EmberLens v0.8.1 — Usability redesign

## Interface changes
- Added a three-step guided entry flow: choose a study area, explore observations, compare sensors.
- Simplified the primary navigation labels and reduced the number of top-level destinations.
- Added a responsive, horizontally scrollable navigation rail on mobile instead of hiding navigation entirely.
- Added automatic active-section highlighting while scrolling.
- Added keyboard-visible focus styles, smooth anchor navigation, and reduced-motion support.
- Preserved the existing API routes, scientific methods, data-source labels, and analysis panels.

## Validation
- Python test suite: 57 passed.
- JavaScript syntax check and Python compilation: see release verification.
- No external provider credentials or user data are included.
