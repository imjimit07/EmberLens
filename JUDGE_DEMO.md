# Live demo guide

Choose one real, imported case study before presenting. Do not use the simulated practice dataset for a scientific result.

1. Start with the question: “Why did the loaded satellite hotspot count change between these two periods in [region]?”
2. Set the date and region filters used in the completed case-study record. Point out the active data mode and the sources in the profile.
3. Show the daily readings and coverage audit. Say what the dashboard knows, and what it does not know about blank dates.
4. Open **Why did the count change?**. Enter the two documented periods and run the comparison.
5. Read the raw loaded-record change, then the matched-positive-source result. Explain whether the source mix changed and name one limitation displayed by the app.
6. Export the evidence report. It captures the exact query, method version, source rows, result, and limitations for review.
7. Close with the real follow-up from the case-study record. If the result was inconclusive, say so. An honest inconclusive result is better evidence of the safeguard than a made-up conclusion.

Before the presentation, verify that the deployed app loads and that the chosen report is saved locally. Use [EVALUATION_EVIDENCE.md](EVALUATION_EVIDENCE.md) to record the case study and any intended-user task results.
